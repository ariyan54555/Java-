# ☕ Java Learning Journey

A collection of Java programs I wrote while learning Java programming from scratch.

---

## 📁 Projects Included

### 🏛️ Library Management System
A console-based library management system built with Java.

**Features:**
- Add books to the library
- Show all available books
- Issue a book to a user
- Return a book

---

## 🛠️ Technologies Used
- Java (Core)
- IntelliJ IDEA

---

## 🚀 How to Run

1. Clone the repository:
   git clone https://github.com/ariyan54555/Java-.git

2. Open in IntelliJ IDEA

3. Run `Main.java`
